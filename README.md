# WatchChat

**WhatsApp messaging on your Amazfit watch.**

WatchChat brings a WhatsApp-style messaging experience to compatible Amazfit watches, using Beeper and a companion bridge to connect your watch to your messages.

## Features

- Browse chats and contacts from your watch
- Read and send messages
- WhatsApp-inspired conversation interface
- Message reactions
- KeyFlow on-watch keyboard
- Notifications and unread indicators
- Customisable settings
- Designed for round watch displays

## Requirements

- Compatible Amazfit watch
- Zepp app installed on your phone
- Windows PC
- Beeper Desktop
- Internet connection

## Installation

1. Download the latest WatchChat ZIP from this repository.
2. Extract the ZIP file.
3. Open `WatchChat.bat`.
4. Follow the setup instructions in the launcher.

   **You may need to open the `.bat` file again in a new window after Step 2. If you do, keep the previous window open — do not close it.**

5. Follow the remaining instructions to configure the bridge.
6. Install WatchChat onto your watch when prompted.
7. Make sure Beeper Desktop and Zepp are running when using WatchChat.

## Updating

Download the latest version of WatchChat and follow the included instructions. If updating the bridge or watch app, allow the installer to replace the existing files when prompted.
